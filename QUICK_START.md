# 🎯 LANGKAH-LANGKAH PERTAMA (5 MENIT)

1. PREVIEW PORTOFOLIO

# ❓ FAQ & TIPS

Q: Bagaimana cara mengganti warna portofolio?
A: Edit css/style.css, ubah nilai --primary-color dan --secondary-color
Lihat CUSTOMIZATION_GUIDE.md untuk contoh warna lain.

Q: Bagaimana cara menambah project baru?
A: Copy template dari examples.html, paste ke index.html di section projects.
Edit nama, deskripsi, teknologi, dan links.

Q: Bagaimana cara upload foto profil?
A: Copy foto ke assets/images/profile.jpg,
Update index.html sesuai instruksi di CUSTOMIZATION_GUIDE.md

Q: Bisa kah diakses dari website?
A: Ya! Deploy ke GitHub Pages atau Netlify (instruksi ada di DEPLOYMENT_GUIDE.md)

Q: Bagaimana cara mengubah font?
A: Tambahkan font dari Google Fonts ke <head>,
Ubah font-family di css/style.css
Lihat CUSTOMIZATION_GUIDE.md untuk detail.

Q: Semua project saya tidak ada, gimana?
A: Tidak perlu! Mulai dengan template dummy, update seiring waktu.
Yang penting portofolio sudah online dan bisa diakses.

# 📞 SUPPORT & TROUBLESHOOTING

Masalah: File HTML tidak terbuka
└─ Solusi: Gunakan browser (Chrome, Firefox)
Jangan buka dengan Notepad/editor

Masalah: CSS/JS tidak loading
└─ Solusi: Pastikan path relatif benar
Cek console (F12 → Console)

Masalah: Image tidak muncul
└─ Solusi: Pastikan path gambar benar
Pastikan file gambar ada di assets/images/

Masalah: Responsive tidak bekerja di mobile
└─ Solusi: Cek meta viewport tag di <head>
Test di DevTools mobile emulation

Untuk bantuan lebih lanjut:
└─ Baca file dokumentasi (.md files)
└─ Cek MDN Web Docs: https://developer.mozilla.org
└─ Stack Overflow: https://stackoverflow.com
