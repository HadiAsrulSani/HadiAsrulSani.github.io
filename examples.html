💡 Tips & Tricks

1. Menemukan Icon FontAwesome yang Tepat:

  • Kunjungi: https://fontawesome.com/icons
  • Cari dengan nama skill/tool (contoh: "python", "react")
  • Copy class name: fab fa-python
  • Gunakan di HTML: <i class="fab fa-python"></i>

2. Membuat Deskripsi Project yang Baik:

  • ✓ Jelaskan problem yang ingin diselesaikan
  • ✓ Sertakan solusi yang dibuat
  • ✓ Highlight fitur utama
  • ✓ Sebutkan teknologi yang digunakan
  • ✓ Jelaskan hasil/impact (user growth, performance, dll)

3. Optimasi Gambar Project:

  • Ukuran: 800x400px - 1200x600px
  • Format: JPG atau PNG (compressed)
  • File size: Maksimal 500KB
  • Tools: TinyPNG.com atau Squoosh.app

4. Upload Sertifikat ke Google Drive:

  • Upload file ke Google Drive
  • Right-click → Share
  • Set ke "Anyone with the link can view"
  • Copy link: https://drive.google.com/file/d/[ID]/view
  • Paste link ke href di HTML
